## 定位

三份文件結論一致：**不做「另一個行程 App」，做「讓揪團成功、主揪不爆炸」的決策工具**，放在 LINE 旁邊，不取代 LINE。主線：

**建立旅程 → 收集需求 → 決定安排 → 完成預訂 → 旅中執行 → 結算**

## 階段

每個階段結束都要能實際使用，並保留既有行為（離線優先、規則強制、邀請碼 8–12 碼）。

### 階段 0：本文件與 ADR 0011
- 路線圖、移除聊天的決策。

### 階段 1：外觀與導覽（原型的視覺語言）
- 依原型的色票建立淺色／深色主題（`--bg`、`--surface`、`--primary`、`--accent`、圓角 18px 等），沿用 `contrast_test` 確保 WCAG AA。
- 底部導覽：首頁（決定看板）、行程、找人、成員；**無聊天**。
- 套用到現有畫面：登入註冊、首頁、建立／加入旅程、旅程頁、設定。行為不變。
- 截圖基準圖依 README 由 CI 的 `regenerate-goldens` 重產，不在 Windows 本機覆寫。

### 階段 2：決定看板與分享到 LINE（P03、缺點分析 1–3）
- 首頁分「已決定／待決定／我的待辦」，依旅程階段調整順序。
- 先用現有資料：旅程狀態、預計回程時間、待審修改申請、邀請碼（含尚未同步）、行程定案版本。
- 邀請、決定結果一鍵分享（系統分享選單，文字＋連結）。

### 階段 2.5：網頁版加入（P02）
- 邀請連結先開網頁，不用安裝就能看行程、投票、填資料、看帳；最重的功能留在 App。
- 決策見 ADR 0012：同一套 Flutter 程式建置 Web 版、Firebase Hosting、匿名帳號加生日的輕量註冊、邀請連結 `/j/<邀請碼>`。
- 網站隱私權政策與 cookie 說明用 claude-for-legal 的 `privacy-legal` 外掛起草，上線前由律師審閱（0012 第 7 點）。

### 階段 3：成團（P01）
- 意願投票「一定去／想去但看日期／先不要」，取代 +1。
- 成團門檻與截止日；到期顯示結果並產生第一個待辦（填可以的日期）。
- 「意願」與「同意付款」分開（缺點分析第 4 點）。

### 階段 4：決策（P05、P06、P07）
- 景點投票加入「不行」（可匿名）與截止時間；未投視為棄權。需改 ADR 0003 的三段式計分。
- 日期熱度圖：每人塗「可以／勉強／不行」，找出全員或多數可行的連續天數，支援「有人晚一天到」。
- 投票前在地圖上看距離；排不進的高票景點標示原因並給替代方案（沿用 0003 的備選清單）。

### 階段 5：分工、預訂與錢（v1.1：P04、P08、P10、P11、P12、P21）
- **任務認領板**：常見任務模板（依目的地）、截止日；區分「邀請負責／已接受」，可拒絕、改期、交接、退出（缺點分析第 7 點）。
- **預訂狀態**：待確認 → 處理中 → 待確認預訂 → 已預訂待付款 → 已預訂已付款，另有「取消／需重新處理」；完成待辦不等於完成預訂。附確認碼與取消期限，期限前提醒（缺點分析第 6 點、P10）。
- **匿名預算**：總預算、單項上限、住宿品質偏好分開；只顯示交集與「已填成員的暫定範圍」；選項顯示每人分攤與是否超出（缺點分析第 5 點、P08）。
- **代墊與分帳**：誰付、幾人分、幣別、匯率規則事先講好；最少轉帳次數結算；由系統提醒，不由主揪催（P11、P21）。
- **團規與退出**：成團時確認退出時間點與分攤；退出時計算損失與遞補（P12）。

### 階段 6：旅中（v1.2：P09、P13、P17–P20）
- **集合卡回應**：已確認／前往中／已到／會晚到；日期、出口、樓層、地標；變更後重新確認（缺點分析第 8 點、P17）。
- 交通節點往前推算集合時間；錯過車班顯示下一班。
- 離線行程與當地語言地址（P18）；分組模式。
- 雨天備案與 10 分鐘快速投票，當日隊長拍板（P19）。
- 個人卡（飲食、步調）、旅客資料卡（護照英文名、效期）、緊急資訊卡（平常隱藏，按緊急才顯示），加密並可於旅程結束後刪除（P09、P13、P20，需更新 0008）。

### 階段 7：旅程後（P23）
- 旅程回顧、一鍵複製團隊、下次想去哪。

## 治理規則要重新決定（缺點分析第 9 點）

ADR 0007 第 5、6 點（連拒兩次抽籤交接、2–3 人團隊長退出即解散）會讓人覺得被限制。建議：
- 交接改為自願；沒人接手時旅程照常，由正副隊長以外的成員也能繼續使用。
- 管理、付款、照顧（未成年）三種角色分開。
- 區分個人封存、退出、整團結束與刪除。

**使用者已同意改成自願交接**（2026-11-04）。這會改 0007，需另開 ADR，並與階段 5 一起做。
